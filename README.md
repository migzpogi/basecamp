# basecamp

### Working Directory
All commands listed below assume that the working directory is the project root folder.  
```
$> cd ~\basecamp
$> pwd  
~\basecamp

$> ls
docs
lib
...
requirements.txt
webapp.py
```

### Running the app
```
$> python webapp.py
* Serving Flask app 'webapp'
* Debug mode: off
* Running on http://localhost:8080
Press CTRL+C to quit
```
